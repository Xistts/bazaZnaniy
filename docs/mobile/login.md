# Авторизация в мобильном приложении

## Назначение

Экран авторизации используется для входа пользователя в мобильное приложение **Алмаз**.

## Основной сценарий

1. Пользователь вводит логин и пароль.
2. Приложение отправляет запрос на сервер.
3. Сервер проверяет данные.
4. Если вход успешен — приложение сохраняет токены.
5. Если требуется 2FA — пользователь переходит на экран подтверждения.

!!! note "Важно"
    Если сервер возвращает необходимость двухфакторной авторизации, приложение не должно сразу считать пользователя авторизованным.

## Ошибки

| Ошибка | Описание | Что делать |
|---|---|---|
| Неверный логин или пароль | Пользователь ввёл неправильные данные | Показать понятное сообщение |
| Истёк пароль | Сервер требует смену пароля | Показать инструкцию |
| Нет сети | Запрос не дошёл до сервера | Предложить повторить попытку |
| Таймаут | Сервер долго не отвечает | Предложить обновить список или повторить вход |

## Пример сообщения пользователю

!!! warning "Ошибка входа"
    Не удалось выполнить вход. Проверьте логин, пароль и подключение к интернету.
