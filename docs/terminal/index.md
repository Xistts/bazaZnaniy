Приложение **«Алмаз-Онлайн»** для терминала **Centerm K9** предназначено для совершения выплат физическим лицам с использованием POS-терминалов по платёжным шлюзам **ПСБ**.

Приложение используется для быстрых и удобных денежных переводов физическим лицам и обеспечивает безопасное выполнение транзакций.

## Назначение приложения

Приложение позволяет выполнять денежные переводы физическим лицам через подключённые платёжные шлюзы.

Основная задача приложения — упростить проведение выплат и предоставить пользователю удобный интерфейс для работы с переводами.

---

## Основные функции

В приложении доступны следующие основные функции:

| Функция | Описание |
|---|---|
| **Перевод по номеру карты** | Пользователь вводит номер банковской карты получателя |
| **Перевод по номеру телефона** | Пользователь вводит номер телефона получателя для выполнения перевода |

---

## Перевод по номеру карты

При переводе по номеру карты пользователь указывает номер банковской карты получателя.

После ввода данных приложение выполняет проверку и позволяет перейти к проведению выплаты.

---

## Перевод по номеру телефона

При переводе по номеру телефона пользователь указывает номер телефона получателя.

Данный способ может использоваться для перевода через доступный платёжный сценарий, если он поддерживается подключённым шлюзом.

---

## Безопасность

Для защиты аккаунта пользователя и операций в приложении предусмотрены механизмы безопасности.

### Двухфакторная аутентификация

Для защиты аккаунта используется **двухфакторная аутентификация**, далее **2FA**.

2FA помогает подтвердить вход пользователя и снизить риск несанкционированного доступа.

### Пин-код для быстрого доступа

В приложении предусмотрена установка **пин-кода**.

Пин-код используется для быстрого доступа в приложение в течение рабочего дня.

!!! info "Примечание"
    Пин-код упрощает повторный вход в приложение, но не заменяет основные меры защиты учётной записи.

---

## Важные особенности

!!! warning "Важно"
    Перед проведением выплаты необходимо проверить корректность введённых данных получателя: номер карты или номер телефона.

!!! tip "Рекомендация"
    Для безопасной работы не передавайте учётные данные, коды подтверждения и пин-код третьим лицам.
