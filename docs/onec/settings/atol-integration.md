В модуле Алмаз предусмотрена интеграция с системой **онлайн-кассы Атол**.

Если включить функционал онлайн-кассы Атол и пройти процедуру авторизации, при совершении оплаты будет активирована интеграция с системой Атол.

---

## Включение функционала Атол

Для включения интеграции необходимо установить флаг:

**«Использовать функционал “Онлайн касса Атол”»**

После установки флага система предложит пройти процедуру авторизации в Атол.

!!! info "Примечание"
    Интеграция с Атол используется при оплате и позволяет задействовать онлайн-кассу в процессе проведения операции.

---

## Авторизация в системе Атол

В открывшемся окне необходимо ввести учётные данные, полученные после регистрации в системе Атол:

- логин;
- пароль.

После заполнения данных нажмите кнопку **«Авторизоваться»**.

![Настройка модуля](../../assets/onec/23.png)

---

## Успешная авторизация

После успешной авторизации появится сообщение:

**«Авторизация выполнена успешно»**

После появления этого сообщения нажмите кнопку **«Далее»** для перехода к следующему этапу настройки.

---

## Выбор ККТ

На следующем этапе откроется окно с таблицей доступных ККТ.

В таблице будут отображены ККТ, доступные для выбранной учётной записи Атол.

Для завершения настройки выполните следующие действия:

1. Выберите нужную ККТ из списка.
2. Нажмите кнопку **«Установить основной ККТ»**.
3. После установки основной ККТ нажмите кнопку **«Закрыть»**.

После этого настройка интеграции онлайн-кассы Атол будет завершена.

---

!!! warning "Важно"
    Для корректной работы интеграции необходимо использовать действующие учётные данные Атол и выбрать основную ККТ.
