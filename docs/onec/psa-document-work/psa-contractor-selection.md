Если ломосдатчик не является новым клиентом и уже существует в справочнике **«Контрагенты»**, его необходимо выбрать в поле **«Ломосдатчик»**.

После выбора контрагента остальные поля документа будут заполнены автоматически.

Если автоматическое заполнение не произошло, значит в карточке соответствующего контрагента информация указана не в полном объёме.

!!! info "Примечание"
    Для корректного автоматического заполнения рекомендуется проверить карточку контрагента и заполнить необходимые сведения.

---

## Способы выбора ломосдатчика

Выбор значения в поле **«Ломосдатчик»** может быть выполнен несколькими способами:

- явный выбор из списка;
- поиск по фамилии;
- поиск по номеру телефона.

---

## Выбор из списка

Пользователь может явно выбрать нужного контрагента из справочника **«Контрагенты»**.

После выбора ломосдатчика система заполнит остальные поля документа данными из карточки контрагента.

---

## Поиск по фамилии

В поле **«Ломосдатчик»** можно ввести несколько символов фамилии физического лица.

После ввода система отобразит список контрагентов, фамилия которых соответствует заданным критериям.

Выберите нужного контрагента из предложенного списка.

---

## Поиск по номеру телефона

Также можно выполнить поиск по номеру телефона.

Для запуска автоматического поиска достаточно ввести первые несколько цифр номера телефона.

Если в справочнике **«Контрагенты»** существует контрагент с указанным номером телефона, система автоматически установит его в поле **«Ломосдатчик»** и заполнит остальные поля документа.

---

## Преимущества поиска

Использование поиска по фамилии или номеру телефона позволяет:

- сократить время создания документа;
- быстрее найти уже существующего ломосдатчика;
- уменьшить количество ручного ввода;
- снизить риск ошибок при заполнении данных.

!!! tip "Рекомендация"
    Если ломосдатчик уже обращался ранее, сначала попробуйте найти его по номеру телефона или фамилии. Это ускорит работу приёмщика и поможет избежать создания дублей в справочнике **«Контрагенты»**.
