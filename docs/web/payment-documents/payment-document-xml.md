В системе **«Алмаз-Онлайн»** можно добавить новый платёжный документ из внешней учётной системы с помощью загрузки XML-файла.

После успешной загрузки документ появится в **Реестре платёжных документов**.

---

## Загрузка XML-файла

Для добавления нового документа из учётной системы выполните следующие действия:

1. Нажмите кнопку **«Загрузить документ»**.

2. Выберите необходимый **XML-файл**.

После успешной загрузки система отобразит уведомление.

В **Реестре платёжных документов** появится новая запись.

!!! info "Примечание"
    XML-файл должен быть сформирован в формате, поддерживаемом системой **«Алмаз-Онлайн»**.

![ПСА](../../assets/web/images/payment-document/12.png)

---

## Продолжение оформления документа

Чтобы продолжить оформление и оплату загруженного документа:

1. Найдите загруженный документ в **Реестре платёжных документов**.

2. Откройте панель действий записи.

3. Нажмите кнопку **«Открыть»**.

После этого откроется форма документа, где можно проверить данные и продолжить оформление.

---

## Краткая схема загрузки

1. Нажмите **«Загрузить документ»**.
2. Выберите XML-файл.
3. Загрузите файл.
4. Дождитесь уведомления об успешной загрузке.
5. Найдите новую запись в реестре.
6. Откройте панель действий записи.
7. Нажмите **«Открыть»**.
8. Продолжите оформление и оплату документа.

---

## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Файл не загружается | Выбран файл неподдерживаемого формата | Проверьте, что выбран файл с расширением `.xml` |
| Система не принимает XML | Файл сформирован в некорректном формате | Проверьте файл во внешней учётной системе |
| Документ не появился в реестре | Загрузка не была завершена или возникла ошибка | Повторите загрузку и проверьте уведомление системы |
| Не получается открыть документ | Недостаточно прав или документ загружен с ошибкой | Проверьте права пользователя и корректность файла |

!!! warning "Важно"
    Перед оплатой загруженного документа проверьте корректность данных: получателя, суммы, способа оплаты и реквизитов.
