В системе **«Алмаз-Онлайн»** можно создать полную копию платёжного документа, если банк отказал в проведении платежа.

Дублирование используется для повторной попытки оплаты по документу, который находится в статусе **«Отказ»**.

---

## Когда доступно дублирование

Дублирование платежа доступно, если:

- банк отказал в проведении платежа;
- в реестре ПСА документ отображается со статусом **«Отказ»**;
- у пользователя есть право на дублирование платежа.

!!! info "Примечание"
    При дублировании создаётся новый платёжный документ с теми же данными. Новый документ появляется в реестре со статусом **«Создан»**.

---

## Как продублировать платёж

Для создания полной копии платёжного документа выполните следующие действия:

1. Перейдите в **Реестр ПСА** или **Реестр платёжных документов**.

2. Найдите документ со статусом **«Отказ»**.

3. Раскройте меню управления нужного документа.

4. Нажмите кнопку **«Дублировать платёж»**.

![ПСА](../../assets/web/images/payment-document/14.png)

После выполнения действия в реестре появится такой же документ со статусом **«Создан»**.

![ПСА](../../assets/web/images/payment-document/15.png)

---

## Повторная оплата

После создания копии документа можно выполнить повторную попытку оплаты.

Для этого:

1. Откройте созданный документ со статусом **«Создан»**.
2. Проверьте данные документа.
3. При необходимости исправьте сведения.
4. Перейдите к оплате.
5. Выберите платёжный шлюз.
6. Выполните оплату.


---

## Права на дублирование платежа

По умолчанию дублировать платёж могут пользователи с ролями:

| Роль | Доступ к дублированию |
|---|---|
| **Администратор** | Доступно по умолчанию |
| **Бухгалтер** | Доступно по умолчанию |
| **Кассир** | Требуется отдельное разрешение |

Для пользователя с ролью **«Кассир»** возможность дублирования платежа необходимо включить отдельно.

---

## Как выдать право кассиру

Чтобы разрешить пользователю с ролью **«Кассир»** дублировать платежи, выполните следующие действия:

1. Перейдите в меню **«Администрирование»**.

2. Откройте подраздел **«Учётные записи»**.

3. Выберите нужного пользователя.

4. Нажмите **«Настройки прав»**.

5. В списке разрешений найдите право **«Дублирование платежа»**.

6. Включите данное разрешение.

7. Сохраните изменения.

!!! info "Примечание"
    Изменять права пользователя по умолчанию могут пользователи с ролью **«Администратор»**.

---


## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Нет кнопки **«Дублировать платёж»** | У пользователя нет соответствующего права | Проверить роль и право **«Дублирование платежа»** |
| Кассир не может дублировать платёж | Право не выдано вручную | Включить разрешение в настройках прав пользователя |
| Новый документ снова получил отказ | Причина отказа не была устранена | Проверить данные платежа и причину отказа банка |
| Нельзя изменить права пользователя | У текущего пользователя нет прав администратора | Выполнить настройку под пользователем с ролью **«Администратор»** |

!!! tip "Рекомендация"
    Используйте дублирование только после проверки причины отказа. Это поможет избежать повторного отклонения платежа банком.
