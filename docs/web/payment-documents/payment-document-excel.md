В системе **«Алмаз-Онлайн»** можно загрузить платёжные документы из Excel-файла.

Этот способ используется, если необходимо загрузить несколько документов, подготовленных во внешней учётной системе или вручную по образцу.

---

## Загрузка Excel-файла

Для загрузки документов выполните следующие действия:

1. Нажмите кнопку **«Загрузить документ»**.

2. Выберите Excel-файл, заполненный по образцу.

3. Загрузите файл в систему.

!!! info "Образец файла"
    Для загрузки документов используйте Excel-файл, заполненный по установленному образцу.

    [Скачать образец загрузки Excel](../../assets/web/files/obrazec-zagruzki.xlsx)

---

## Правила заполнения файла

В Excel-файле каждый новый **ПСА** необходимо указывать в новой строке.

Одна строка соответствует одному загружаемому документу.

!!! warning "Важно"
    Если поля в Excel-файле заполнены неверно, при попытке загрузки в реестр откроется окно с подсказками. В нём будет указано, какие данные необходимо исправить.

---

## Проверка данных при загрузке

Система проверяет корректность заполнения Excel-файла.

Если в файле есть ошибки:

- записи не будут добавлены в реестр;
- система отобразит окно с подсказками;
- пользователю необходимо исправить данные в Excel-файле;
- после исправления файл нужно загрузить повторно.

Только после правильного заполнения всех полей записи появятся в **Реестре платёжных документов**.

## Поля Excel-файла

| Поле | Обязательность | Правило заполнения |
|---|---|---|
| **Номер** | Необязательно | Если поле не заполнено, номер будет присвоен системой |
| **Дата создания** | Необязательно | Если поле не заполнено, будет указана текущая дата загрузки |
| **Резидент** | Обязательно | Заполняется значением **«Да»** или **«Нет»** |
| **Фамилия** | Обязательно | Указывается фамилия ломосдатчика |
| **Имя** | Обязательно | Указывается имя ломосдатчика |
| **Отчество** | Необязательно | Указывается при наличии |
| **Телефон** | Необязательно | Указывается номер телефона ломосдатчика |
| **Серия паспорта** | Необязательно | Указывается серия паспорта |
| **Номер паспорта** | Необязательно | Указывается номер паспорта |
| **Дата выдачи паспорта** | Необязательно | Указывается дата выдачи паспорта |
| **Сумма** | Необязательно | Указывается сумма выплаты |
| **Номер карты** | Необязательно | Указывается номер банковской карты |
| **Держатель** | Необязательно | Указывается держатель карты |

---

## Краткая схема загрузки

1. Нажмите **«Загрузить документ»**.
2. Выберите Excel-файл, заполненный по образцу.
3. Загрузите файл.
4. Если система покажет ошибки, исправьте данные в Excel-файле.
5. Загрузите исправленный файл повторно.
6. После успешной проверки записи появятся в реестре.

---

## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Файл не загружается | Выбран файл неподдерживаемого формата | Проверьте, что выбран Excel-файл |
| Появилось окно с подсказками | В файле есть ошибки заполнения | Исправьте указанные поля и загрузите файл повторно |
| Записи не появились в реестре | Файл не прошёл проверку | Проверьте все обязательные поля |
| Не заполнен номер документа | Это поле необязательное | Номер будет присвоен системой |
| Не заполнена дата создания | Это поле необязательное | Будет указана текущая дата загрузки |
| Некорректно заполнено поле «Резидент» | Указано значение, отличное от «Да» или «Нет» | Укажите **«Да»** или **«Нет»** |

!!! tip "Рекомендация"
    Перед загрузкой проверьте, что обязательные поля **«Резидент»**, **«Фамилия»** и **«Имя»** заполнены для каждой строки.
