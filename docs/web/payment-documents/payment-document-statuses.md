Платёжный документ в системе **«Алмаз-Онлайн»** может иметь разные статусы.

Статус показывает текущее состояние документа: создан ли он, находится ли в обработке, успешно ли оплачен или был отклонён.

---

## Список статусов

Платёжный документ может иметь **7 статусов**.

| Обозначение в веб-интерфейсе | Обозначение в API | Описание |
|---|---|---|
| **Создан** | `init` | Платёжный документ создан |
| **В процессе** | `process` | Платёжный документ обрабатывается системой **«Алмаз-Онлайн»** |
| **В обработке** | `processing` | Платёжный документ обрабатывается системой банка |
| **Оплачен** | `successful` | Платёжный документ успешно оплачен |
| **Отказ** | `error` | Банк отказал в проведении платежа |
| **Ожидание** | `awaitingConfirmation` | Ожидается подтверждение оплаты пользователем по СБП |
| **Отмена** | `canceled` | Оплата отменена пользователем при подтверждении платежа по СБП |

---

## Описание статусов

### Создан

Статус **«Создан»** означает, что платёжный документ создан в системе, но оплата по нему ещё не выполнена.

В API данный статус обозначается как:

`init`

!!! info "Примечание"
    На этом этапе результат платежа ещё не является окончательным.

---

### В процессе

Статус **«В процессе»** означает, что платёжный документ обрабатывается системой **«Алмаз-Онлайн»**.

В API данный статус обозначается как:

`process`

!!! info "Примечание"
    На этом этапе результат платежа ещё не является окончательным.

---

### В обработке

Статус **«В обработке»** означает, что платёжный документ передан в банк и обрабатывается банковской системой.

В API данный статус обозначается как:

`processing`

!!! info "Примечание"
    На этом этапе результат платежа ещё не является окончательным.

---

### Оплачен

Статус **«Оплачен»** означает, что платёжный документ успешно оплачен.

В API данный статус обозначается как:

`successful`

!!! info "Примечание"
    На этом этапе результат платежа является окончательным.

---

### Отказ

Статус **«Отказ»** означает, что банк отказал в проведении платежа.

В API данный статус обозначается как:

`error`

!!! info "Примечание"
    На этом этапе результат платежа является окончательным.

---

### Ожидание

Статус **«Ожидание»** используется при оплате через **СБП**.

Он означает, что ожидается подтверждение оплаты пользователем.

В API данный статус обозначается как:

`awaitingConfirmation`

!!! info "Примечание"
    На этом этапе результат платежа ещё не является окончательным.

---

### Отмена

Статус **«Отмена»** означает, что пользователь отменил оплату при подтверждении платежа по **СБП**.

В API данный статус обозначается как:

`canceled`

!!! info "Примечание"
    На этом этапе результат платежа является окончательным.
---
