На электронную почту, указанную в договоре, пользователю автоматически отправляется письмо с паролем.

Полученный пароль действителен только для **первичной авторизации** в системе **«Алмаз-Онлайн»**.

---

## Первичный вход в систему

Для входа в систему выполните следующие действия:

1. Перейдите по ссылке:

    [https://almaz-online.ru](https://almaz-online.ru)

2. На приветственном окне нажмите кнопку **«Авторизация»**.

3. В соответствующих полях укажите:

    - логин;
    - пароль из письма, полученного по электронной почте.

4. Нажмите кнопку **«Войти»**.

!!! info "Двухфакторная защита"
    В системе **«Алмаз-Онлайн»** подключена двухфакторная защита учётной записи.

---

## Подтверждение входа

После успешного ввода логина и пароля на номер мобильного телефона, указанный ранее, придёт код аутентификации.

Для подтверждения входа:

1. Введите полученный код в соответствующее поле.
2. Нажмите кнопку **«Войти»**.

После подтверждения кода откроется окно активации двухфакторной аутентификации.

---

## Активация двухфакторной аутентификации

Для активации двухфакторной аутентификации необходимо отсканировать QR-код приложением для двухфакторной аутентификации.

Например:

- **Яндекс.Ключ**;
- Google Authenticator;
- Microsoft Authenticator;
- другое приложение для генерации одноразовых кодов.

!!! warning "Важно"
    Сохраните доступ к приложению двухфакторной аутентификации. Оно потребуется для последующих входов в систему.

---

## Создание нового пароля

После активации двухфакторной аутентификации система откроет окно, в котором необходимо сгенерировать новый пароль.

Для этого выполните следующие действия:

1. В верхнее поле введите текущий пароль из письма.

2. Нажмите кнопку **«Сгенерировать пароль»**.

3. В поле **«Новый пароль»** будет автоматически сгенерировано новое значение.

    Сгенерированный пароль также автоматически добавится в буфер обмена.

4. При необходимости нажмите на переключатель приватности — **иконку глазка**, чтобы увидеть новый пароль.

5. Запомните или сохраните новый пароль в надёжном месте.

6. Подтвердите новый пароль в соответствующем поле.

7. Завершите смену пароля.

!!! danger "Важно"
    Никому не передавайте свой пароль и коды двухфакторной аутентификации.

---

## Повторная авторизация после смены пароля

После создания нового пароля необходимо повторно авторизоваться в системе.

Для этого:

1. Нажмите кнопку **«Войти»**.
2. Введите адрес электронной почты.
3. Введите новый пароль.
4. Подтвердите вход с помощью двухфакторной аутентификации.

После успешной авторизации система откроет стартовое окно.

---

## Срок действия пароля

Срок действия нового пароля составляет **90 дней**.

По истечении срока действия пароля система предложит сменить его.


---

## Восстановление пароля

В случае утери пароля необходимо обратиться к пользователю с ролью **«Администратор»** вашей организации.

Самостоятельное восстановление пароля пользователем не выполняется.

---

## Действия администратора для восстановления пароля

Для восстановления пароля администратору необходимо:

1. Перейти в меню:

    **Администрирование → Учётные записи**

2. Выбрать из списка учётную запись сотрудника, которому необходимо восстановить пароль.

3. Нажать кнопку **«Редактировать»**.

4. Развернуть вкладку с данными пользователя.

5. Нажать кнопку **«Сгенерировать пароль»**.

6. Пользователю необходимо зайти на адрес электронной почты, указанный в его учётной записи.

7. Далее пользователь продолжает выполнение авторизации как при первом входе в систему.
