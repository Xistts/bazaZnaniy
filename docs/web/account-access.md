Раздел используется для настройки доступа структурных подразделений к платёжным счетам и установки лимитов на проведение выплат.

Лимиты позволяют ограничивать доступную сумму платежей для связки:

**Счёт → Структура**

---

## 1. Описание лимитов

Лимиты делятся на две категории:

| Категория | Описание |
|---|---|
| **Периодические лимиты** | Действуют постоянно до ручного отключения |
| **Разовые лимиты** | Действуют только в пределах выбранного периода и автоматически отключаются после его завершения |

Введённое значение в поля **«Сутки»**, **«Неделя»**, **«Месяц»** ограничивает общую доступную сумму платежей для пары **«Счёт — Структура»** в рамках соответствующего периода.

---

## Временные интервалы лимитов

| Лимит | Период действия |
|---|---|
| **Сутки** | С 00:00:00 до 23:59:59 текущего дня |
| **Неделя** | С 00:00:00 понедельника до 23:59:59 воскресенья |
| **Месяц** | С первого до последнего числа календарного месяца |

Установка флага напротив поля лимита включает действие лимита.

Снятие флага отключает действие лимита.

!!! info "Пример"
    Если флаг для суточного лимита был установлен в **10:00**, а снят в **10:30**, то проверка суммы платежей по данному счёту работает только в рамках указанного периода времени.

---

## 1.1. Отличия периодических и разовых лимитов

### Периодический лимит

Периодический лимит действует до тех пор, пока пользователь вручную не снимет флаг активности.

Флаг активности для периодического лимита включается и отключается только вручную.

### Разовый лимит

Флаг активности для разового лимита автоматически снимается по истечении соответствующего периода:

- суток;
- недели;
- месяца.

Разовый лимит имеет более высокий приоритет по сравнению с периодическим лимитом.

!!! warning "Пример приоритета"
    Если размер периодического суточного лимита равен **100 000**, а размер разового суточного лимита равен **0**, проведение платежей с данного счёта будет недоступно до окончания текущего дня.

---

## 1.2. Особенности действия лимитов

При настройке лимитов необходимо учитывать следующие правила:

1. Размер суточного лимита не может превышать размер недельного лимита.
2. Размер суточного лимита не может превышать размер месячного лимита.
3. Размер недельного лимита не может превышать размер месячного лимита.
4. В качестве размера лимита может быть установлено значение **0**.

!!! danger "Нулевой лимит"
    Если лимит активен и его значение равно **0**, проведение платежей с данного счёта запрещено.

Такой подход можно использовать, например, для разового суточного лимита, чтобы полностью запретить проведение платежей на одни сутки.

---

## 1.3. Поле «Доступно»

Справа от полей ввода размеров лимитов находится поле **«Доступно»**.

В этом поле отображается остаток по соответствующему лимиту.

Значение рассчитывается по формуле:

**Доступно = Размер лимита − Сумма проведённых платежей за период**

Например, если установлен суточный лимит **100 000**, а за текущие сутки уже проведены платежи на **35 000**, то в поле **«Доступно»** будет отображаться:

**65 000**

---

## 1.4. Право пользователя

За возможность редактирования лимитов отвечает право:

**«Редактирование лимитов шлюзов»**

По умолчанию это право установлено только у роли **«Администратор»**.

!!! warning "Важно"
    Если пользователь не видит возможность редактирования лимитов, необходимо проверить его роль и наличие права **«Редактирование лимитов шлюзов»**.

---

## 2. Добавление доступов и установка лимитов

## 2.1. Авторизация в системе

Для установки лимитов необходимо авторизоваться в системе **«Алмаз-Онлайн»** в роли администратора базовой организации.

Авторизация выполняется через окно входа в систему и двухфакторной аутентификации.

---

## 2.2. Переход в реестр организаций

После успешной авторизации необходимо перейти в меню:

**Администрирование → Реестр организаций**

---

## 2.3. Открытие управления счетами

На странице **«Реестр организаций»** выполните следующие действия:

1. Выберите **базовую организацию**.
2. Откройте меню действий.
3. Выберите пункт **«Управление счетами»**.

---

## 2.4. Просмотр доступов к счёту

В открывшемся окне **«Доступ к счёту»** отображается информация о существующих доступах к платёжным счетам.

В списке можно увидеть, какие структуры уже имеют доступ к определённым счетам.

---

## 2.5. Добавление доступа к счёту

Для добавления нового доступа нажмите кнопку **«Добавить доступ»**.

В открывшейся форме выберите связку:

**Счёт → Структура**

Также при необходимости заполните:

- название счёта;
- комментарий.

!!! info "Примечание"
    Комментарий можно использовать для пояснения назначения доступа или особенностей использования счёта.

---

## 2.6. Установка лимитов

Для установки лимитов выполните следующие действия:

1. Перейдите во вкладку **«Лимиты»**.
2. Установите необходимые значения для лимитов:
    - **Сутки**;
    - **Неделя**;
    - **Месяц**.
3. Установите флаги активности напротив нужных лимитов.
4. Проверьте значения в поле **«Доступно»**.
5. Нажмите кнопку **«Сохранить»**.

!!! warning "Важно"
    Перед сохранением проверьте, что суточный лимит не превышает недельный и месячный, а недельный лимит не превышает месячный.

---

## 2.7. Изменение уже установленных лимитов

Для изменения настроек уже установленных лимитов:

1. Откройте окно **«Доступ к счёту»**.
2. Выберите из списка необходимую структуру.
3. Нажмите кнопку **«Открыть настройки»**.
4. Перейдите во вкладку **«Лимиты»**.
5. Измените необходимые значения.
6. Нажмите кнопку **«Сохранить»**.

---

## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Нет кнопки редактирования лимитов | У пользователя нет права на редактирование лимитов | Проверить роль и право **«Редактирование лимитов шлюзов»** |
| Не удаётся сохранить лимит | Значение суточного лимита превышает недельный или месячный | Проверить соотношение лимитов |
| Платежи не проходят | Активен лимит со значением `0` | Проверить активные разовые и периодические лимиты |
| В поле «Доступно» маленькая сумма | По счёту уже были проведены платежи в текущем периоде | Проверить историю платежей за сутки, неделю или месяц |

!!! tip "Рекомендация"
    При временной блокировке платежей удобнее использовать **разовый суточный лимит со значением 0**. После завершения суток такой лимит автоматически перестанет действовать.
