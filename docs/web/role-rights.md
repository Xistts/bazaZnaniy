# 7. Права ролей

## Назначение

В системе **«Алмаз-Онлайн»** пользователи работают в рамках назначенных ролей.

Роль определяет, какие разделы системы доступны пользователю и какие действия он может выполнять.

---

## Роли пользователей

В системе предусмотрены следующие роли:

| Роль | Описание |
|---|---|
| **Администратор** | Пользователь с расширенными правами управления системой, пользователями, организациями и настройками |
| **Бухгалтер** | Пользователь, работающий с финансовыми операциями, документами и выплатами в рамках предоставленных прав |
| **Кассир** | Пользователь, выполняющий операции, связанные с приёмом и выплатами, в рамках назначенных доступов |

---

## Управление правами

Для каждой роли предусмотрен собственный набор прав.

По умолчанию редактировать права может пользователь с ролью **«Администратор»**.

!!! warning "Важно"
    Настройка прав влияет на доступ пользователя к разделам системы и возможность выполнения операций. Изменять права следует только при понимании последствий.

---

## Обозначения в таблице прав

В таблице прав используются следующие обозначения:

| Обозначение | Описание |
|---|---|
| **Разрешено** | Право доступно роли по умолчанию |
| **Выдаются** | Право может быть назначено вышестоящей ролью |
| **Недоступно** | Право недоступно для данной роли |

---

## Рекомендации по настройке прав

При настройке прав рекомендуется соблюдать принцип минимально необходимого доступа.

Это означает, что пользователю следует выдавать только те права, которые необходимы ему для выполнения рабочих задач.

!!! tip "Рекомендация"
    Не назначайте расширенные права пользователям без необходимости. Для административных действий используйте отдельные учётные записи с ролью **«Администратор»**.

---

## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Пользователь не видит нужный раздел | У роли нет соответствующего права | Проверить роль и настройки прав |
| Пользователь не может выполнить действие | Право не выдано или недоступно для роли | Проверить таблицу прав |
| Пользователь видит лишние разделы | Назначены избыточные права | Ограничить права пользователя |
| Нельзя изменить права | У текущего пользователя нет права на редактирование прав | Войти под пользователем с ролью **«Администратор»** |
