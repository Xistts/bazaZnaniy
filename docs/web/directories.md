## Транспорт

Подраздел **«Транспорт»** предназначен для хранения реестра созданного транспорта.

Записи из этого справочника используются при дальнейшем оформлении платёжных документов.

![Транспорт](../assets/web/images/directories/2.png)

### Создание транспорта

Чтобы создать транспорт, выполните следующие действия:

1. Перейдите в раздел меню **«Справочники»**.
2. Откройте подраздел **«Транспорт»**.
3. Нажмите кнопку **«Добавить»**.
4. В открывшемся окне заполните необходимые данные.
![Транспорт](../assets/web/images/directories/3.png)

5. Нажмите кнопку **«Сохранить»**.

После сохранения в реестре отобразится новая запись транспорта.

### Действия с записью транспорта

Для каждой записи транспорта доступны действия:

| Действие | Описание |
|---|---|
| **Редактировать** | Изменение данных транспорта |
| **Удалить** | Удаление записи транспорта из реестра |

!!! tip "Рекомендация"
    Перед созданием платёжных документов заранее внесите нужный транспорт в справочник, чтобы его можно было быстро выбрать при оформлении.

## Краткая схема работы со справочниками

1. Перейдите в раздел **«Справочники»**.
2. Выберите нужный подраздел:
    - **Транспорт**;
    - **Номенклатура**;
    - **Контрагенты**.
3. Нажмите кнопку **«Добавить»**.
4. Заполните поля формы.
5. Нажмите кнопку **«Сохранить»**.
6. Проверьте, что новая запись появилась в реестре.

---

## Возможные проблемы

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| Запись не сохраняется | Не заполнены обязательные поля | Проверить форму и заполнить обязательные поля |
| Неверные данные в документе | В справочнике указаны некорректные сведения | Отредактировать запись в справочнике |

!!! tip "Рекомендация"
    Регулярно проверяйте актуальность справочников. Это поможет избежать ошибок при оформлении платёжных документов.
