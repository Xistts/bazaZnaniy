Платёжный шлюз используется для подключения банковского счёта организации к системе **«Алмаз-Онлайн»**.

Через платёжный шлюз выполняются безналичные выплаты физическим лицам за сданный лом чёрных и цветных металлов.
---

## Добавление счёта

Для добавления платёжного шлюза выполните следующие действия:

1. Откройте раздел меню **«Администрирование»**.

2. Перейдите в подраздел **«Реестр организаций»**.

3. В реестре выберите **Базовую организацию**.

4. Нажмите кнопку **«Добавить счёт»**.

После этого откроется карточка добавления счёта.

---

## Выбор платёжного шлюза

В открывшейся карточке выберите платёжный шлюз банка, с которым заключила договор ваша организация.

После выбора платёжного шлюза нажмите кнопку **«Добавить»**.

!!! note "Примечание"
    В списке необходимо выбрать именно тот банк, по которому у организации заключён договор.

---

## Открытие настроек шлюза

После добавления платёжного шлюза:

1. Выделите добавленный платёжный шлюз в списке.

2. Нажмите кнопку **«Открыть настройки»**.

Откроется форма настройки выбранного платёжного шлюза.

---

## Заполнение настроек

Заполните поля настройки в соответствии с инструкцией по настройке платёжного шлюза.

Инструкция приходит отдельным письмом на электронную почту, указанную при подключении.


!!! warning "Важно"
    Не заполняйте поля произвольными значениями. Все данные необходимо указывать строго в соответствии с инструкцией по настройке платёжного шлюза.

---

## Сохранение настроек

После заполнения всех данных нажмите кнопку **«Сохранить»**.

Если данные заполнены корректно, настройки платёжного шлюза будут сохранены в системе.

---

## Активация платёжного шлюза

Дальнейшую активацию платёжного шлюза выполняет сотрудник системы **«Алмаз»**.

После сохранения данных необходимо связаться с отделом технической поддержки.

!!! danger "Важно"
    Самостоятельная настройка не завершает подключение шлюза полностью. После сохранения параметров обязательно обратитесь в техническую поддержку для дальнейшей активации.

---
