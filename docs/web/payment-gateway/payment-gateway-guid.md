## Назначение

**Guid платёжного шлюза** — это уникальный идентификатор платёжного шлюза в системе **«Алмаз-Онлайн»**.

Он может потребоваться при настройке, проверке подключения или обращении в техническую поддержку.

---

## Как посмотреть Guid платёжного шлюза

Для просмотра Guid платёжного шлюза выполните следующие действия:

1. Перейдите в меню **«Администрирование»**.

2. Откройте подраздел **«Реестр организаций»**.

3. Выберите **базовую организацию**.

4. Нажмите кнопку **«Добавить счёт»**.

5. В открывшемся окне выберите необходимый платёжный шлюз.

6. Нажмите кнопку **«Открыть настройки»**.

7. В верхней левой части окна будет указан **Guid** выбранного платёжного шлюза.
